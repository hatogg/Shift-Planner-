# Shift Planner

Календар робочих змін для Android у стилі Material You.

- **Свої зміни** — назва, коротка позначка, колір, час початку й кінця, перерва; нічні зміни через північ рахуються правильно.
- **Календар** — місяць на екрані, гортання пальцем, натиск на день — вибрати зміну або вихідний і дописати нотатку.
- **Шаблони графіка** — 2/2, день-ніч-два вихідні чи будь-який свій цикл; заповнює календар на 1–12 місяців одним натиском.
- **Статистика** — кількість змін і годин за місяць, вихідні, заробіток за погодинною ставкою.
- **Віджет** — сьогоднішня й наступна зміна та найближчий тиждень на головному екрані.

Усі дані зберігаються лише на телефоні. Android 8.0+. Ліцензія [MIT](LICENSE).

## Встановлення

Завантажте `ShiftPlanner-<версія>.apk` з [останнього релізу](../../releases/latest) прямо на телефоні й відкрийте його.

## Збірка

GitHub Actions збирає APK на кожен push у `main` і викладає його в реліз `v<versionName>`. Локально: Android Studio або `./gradlew assembleRelease` (JDK 17, Android SDK 35).

Підпис: ключ `signing/shiftplanner.jks` лежить у репозиторії, щоб кожна збірка ставилася поверх попередньої. Для публікації в Google Play замініть його власним і передайте паролі секретами `SP_STORE_PASS` / `SP_KEY_PASS`.
